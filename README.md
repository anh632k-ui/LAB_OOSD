## 2. Giới thiệu

Repository được sử dụng để lưu trữ các sơ đồ phân tích và thiết kế hệ thống trong quá trình thực hiện bài thực hành môn Phân tích và Thiết kế Hướng đối tượng.

Các sơ đồ được xây dựng bằng Draw.io (diagrams.net) và lưu dưới định dạng `.drawio` để có thể mở, xem và chỉnh sửa trực tiếp.

Nội dung thực hành bao gồm phân tích nghiệp vụ, thiết kế hệ thống, xây dựng cơ sở dữ liệu SQL Server và hiện thực giao diện ứng dụng bằng C# Windows Forms.

### Ghi chú đối với LAB2, LAB3 và LAB5

Đối với LAB2, LAB3 và LAB5, giảng viên đã cung cấp tài liệu hướng dẫn bao gồm nội dung phân tích, thiết kế hệ thống và mẫu giao diện tương đối đầy đủ.

Do đó, quá trình thực hành em tập trung vào việc xây dựng cơ sở dữ liệu, triển khai giao diện Windows Forms, kết nối dữ liệu và thực hiện các chức năng theo tài liệu giảng viên cung cấp.

Các sơ đồ phân tích và thiết kế đã có sẵn trong tài liệu học tập nên em không vẽ lại thành file Draw.io riêng. Vì vậy, thư mục `IMAGES` không có file `.drawio` tương ứng với LAB2, LAB3 và LAB5.

## 4. Công cụ sử dụng

- **Draw.io (diagrams.net):** Vẽ và chỉnh sửa các sơ đồ.
- **Microsoft SQL Server:** Thiết kế và quản lý cơ sở dữ liệu.
- **SQL Server Management Studio (SSMS):** Tạo bảng, thiết lập quan hệ và kiểm tra dữ liệu.
- **Visual Studio 2022:** Thiết kế và xây dựng ứng dụng C# Windows Forms.
- **Microsoft Word:** Tổng hợp nội dung và kết quả thực hành.
- **Git và GitHub:** Quản lý và lưu trữ các file thiết kế.

## 5. Hướng dẫn mở các sơ đồ

1. Truy cập Repository GitHub: https://github.com/anh632k-ui/LAB_OOSD
2. Mở thư mục `IMAGES`.
3. Chọn file `.drawio` cần xem và tải về máy.
4. Truy cập https://app.diagrams.net/
5. Chọn **File → Open From → Device**.
6. Chọn file `.drawio` đã tải để xem hoặc chỉnh sửa.
